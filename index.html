原理说明

Ghost Bits 核心原理

Java 的 char 为 16 位，byte 为 8 位。当通过 (byte)ch、ch & 0xFF、baos.write(ch) 等方式将 char 转为 byte 时，高 8 位被静默丢弃，仅保留低 8 位。

攻击示例

原始字符: ':'  (U+003A)
替换字符: '爻' (U+2F58)

爻 → 0x2F58 → 二进制:
  0x2F(高8位) | 0x3A(低8位)

(byte)'爻' → 丢弃高8位 → 0x3A → ':'
